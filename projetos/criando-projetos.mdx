# <Icon icon="file" color="#0516ee" size={30} /> Seu projeto

Um projeto representa uma aplicação que será publicada no AmbarksCloud. Nele você define nome, forma de envio, memória, porta interna, variáveis e configurações de build.

## Criar pelo dashboard

1. Clique em `Criar Novo Projeto`.
2. Informe um nome claro para identificar a aplicação.
3. Defina o limite de memória.
4. Escolha `Arquivo ZIP` ou `GitHub Repo`.
5. Configure a porta interna se sua aplicação não usar a porta padrão do runtime.
6. Envie o ZIP ou selecione o repositório.
7. Confirme para iniciar o deploy.

## Campos importantes

| Campo | Dica |
| --- | --- |
| Memória | Comece com um valor seguro; aumente se o build falhar |
| Runtime | Se o runtime não for detectado, selecione manualmente |
| Porta interna | Deve bater com a porta do servidor dentro do container |
| Variáveis | Secrets devem ficar em [variáveis de ambiente](/projetos/variaveis-ambiente) |

## Limites importantes

- Memória por projeto: mínimo `128 MB` e máximo `32768 MB`.
- Deploy via ZIP: tamanho máximo do `.zip` é **100 MB**.
