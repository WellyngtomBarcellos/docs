# <Icon icon="file" color="#0516ee" size={30} /> Seu projeto

Um projeto representa uma aplicação que será publicada no AmbarksCloud. Nele você define nome, forma de envio, memória, porta, variáveis e configurações de build.

## Criar pelo dashboard

1. Clique em `Criar Novo Projeto`.
2. Informe um nome claro para identificar a aplicação.
3. Defina o limite de memória.
4. Escolha `Arquivo ZIP` ou `GitHub Repo`.
5. Configure a porta interna se sua aplicação não usar a porta padrão do runtime.
6. Envie o ZIP ou selecione o repositório.
7. Confirme para iniciar o deploy.

## Campos importantes

| Campo | Quando usar |
| --- | --- |
| Nome | Identifica o projeto no dashboard |
| Memória | Define quanto de RAM a aplicação pode usar |
| Porta interna | Porta em que sua aplicação escuta dentro do container |
| Runtime | Linguagem/ambiente usado quando não há Dockerfile |
| Dockerfile | Caminho do Dockerfile, se você usar um arquivo personalizado |
| Repositório | Projeto GitHub usado no deploy por branch |
| Branch | Branch usada para publicar o projeto |

## Porta interna

A porta interna deve ser a mesma porta usada pela aplicação. Exemplos comuns:

| Tipo de projeto | Porta comum |
| --- | --- |
| Node.js | `3000` |
| Python | `8000` |
| Rust | `8080` |
| PHP | `8000` |
| Site estático | `80` |

Se o deploy concluir mas o site não abrir, a porta interna é uma das primeiras configurações a revisar.

## Antes do primeiro deploy

- Rode o projeto localmente para confirmar que o comando de start funciona.
- Garanta que a aplicação escute em `0.0.0.0`, não apenas em `localhost`.
- Adicione `ambarks.json` se precisar informar comandos diferentes do padrão.
- Use Dockerfile se seu projeto exigir dependências ou passos muito específicos.
