# <Icon icon="code" color="#0516ee" size={30} /> Use sempre os logs e métricas

Logs e métricas ajudam a entender se o deploy funcionou, se a aplicação iniciou corretamente e se ela está consumindo recursos dentro do esperado.

## Logs de deploy

Use os logs de deploy para acompanhar:

- Download ou leitura do código enviado.
- Instalação de dependências.
- Build da aplicação.
- Criação da imagem.
- Inicialização do container.
- Erros de comando, dependência ou porta.

## Logs da aplicação

Depois que o container inicia, os logs mostram a saída do seu processo. Tudo que sua aplicação escreve em stdout/stderr aparece nessa área.

Exemplos úteis:

- Servidor iniciou em qual porta.
- Erro de conexão com banco.
- Variável de ambiente ausente.
- Exceção durante boot da aplicação.

## Métricas

As métricas ajudam a acompanhar o consumo de:

| Métrica | Uso |
| --- | --- |
| CPU | Indica carga de processamento |
| RAM | Mostra memória usada pela aplicação |
| Rede | Ajuda a observar tráfego |

## Como diagnosticar

1. Se o deploy falhou, leia os logs de deploy de cima para baixo.
2. Se o deploy concluiu mas o site não abre, confira logs da aplicação e porta interna.
3. Se a aplicação reinicia ou para, veja se há erro logo após o comando de start.
4. Se falta configuração, revise as variáveis de ambiente.
