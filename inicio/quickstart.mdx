# <Icon icon="golf-flag-hole" color="#0516ee" size={30} /> Vai que é sua

Este guia mostra o caminho mais curto para publicar uma aplicação no **AmbarksCloud**.

<Frame>
  ![Wallpaper](/images/wallpaper.png)
</Frame>

## 1. Prepare seu projeto

Antes de enviar, confira:

| Item | Recomendação |
| --- | --- |
| Comando de start | Tenha um comando que mantenha a aplicação rodando |
| Porta | A aplicação deve escutar em `0.0.0.0` na porta configurada |
| Dependências | Inclua arquivos como `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `requirements.txt` ou equivalentes |
| Arquivos locais | Remova `node_modules`, `.git`, caches e builds desnecessários do ZIP |

## 2. Escolha o formato de envio

- Use **Arquivo ZIP** quando quiser testar rápido ou enviar código sem conectar repositório.
- Use **GitHub Repo** quando quiser publicar a partir de uma branch e facilitar novos deploys.

## 3. Crie o projeto

1. Acesse o dashboard.
2. Clique em `Criar Novo Projeto`.
3. Informe o nome do projeto.
4. Defina a memória disponível.
5. Escolha ZIP ou GitHub.
6. Envie o código ou selecione o repositório.
7. Confirme para iniciar o primeiro deploy.

## 4. Acompanhe os logs

Abra a área de logs do projeto para ver cada etapa do deploy. Se algo falhar, os logs normalmente indicam se o problema está no build, no comando de start, na porta ou em alguma variável ausente.

## 5. Ajuste quando necessário

Se o AmbarksCloud não detectar o projeto corretamente, adicione um arquivo [`ambarks.json`](/projetos/ambarks-json) na raiz com comandos explícitos de instalação, build e start.
