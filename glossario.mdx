# Glossario

| Termo | Significado |
| --- | --- |
| Projeto | Aplicacao configurada no dashboard |
| Deploy | Publicacao de uma versao do projeto |
| Runtime | Ambiente usado para preparar e iniciar a aplicacao |
| `ambarks.json` | Arquivo opcional para definir comandos de build e start |
| Dockerfile | Arquivo opcional para controlar o build da aplicacao |
| Porta interna | Porta em que a aplicacao escuta durante a execucao |
| Variavel de ambiente | Configuracao ou secret passado para a aplicacao |
| Secret | Valor sensivel mascarado no dashboard |
| Build | Etapa que prepara a aplicacao para rodar |
| Start | Comando que inicia a aplicacao |
| Container | Ambiente isolado onde a aplicacao roda |
| Branch | Linha de desenvolvimento usada no deploy pelo GitHub |
| ZIP | Arquivo compactado enviado pelo dashboard |
