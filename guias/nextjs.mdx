## Opção A: Start padrão do Next

```json
{
  "build": {
    "installCommand": "npm ci",
    "buildCommand": "npm run build"
  },
  "run": {
    "command": "npm run start"
  }
}
```

## Configurações no dashboard

- Porta interna: `3000`

Se você precisar de versões específicas do Node, use Dockerfile.
