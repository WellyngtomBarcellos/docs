## Regras rápidas (valem para todos)

1. Garanta um comando de start que mantenha o processo rodando.
2. Para apps web: escute em `0.0.0.0` e use a porta interna correta.
3. Secrets e tokens: use [variáveis de ambiente](/projetos/variaveis-ambiente).
4. Se precisar de comandos customizados: use [`ambarks.json`](/projetos/ambarks-json).
